# M18 Multilingual Intelligence

Approved Church Memory now carries an explicit language profile derived from archived transcript-segment language metadata. English/Kiswahili mixed services are marked code-switched, and bounded Church Memory search can filter by an explicitly requested language without weakening owner/admin scope.

This is metadata-aware retrieval, not a field-accuracy claim. Real code-switch transcription/detection performance still requires M5/M23 permissioned sermon evidence.
