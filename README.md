# RUACH Intelligence

RUACH is a review-first church-service intelligence system: sermon input → scripture detection → operator approval → projector/broadcast/congregation output → immutable archive → reviewed downstream intelligence.

## Current release

**0.4.0rc1 — pre-pilot release candidate**

The local build is implemented and regression-tested through **M22 Deployment & Updates**. **M23 is ready for a real permissioned church pilot but has not been passed in the field.** M24 commercial multi-tenancy/billing is architecture-only and is not deployed.
