# M23 Real Church Pilot Protocol

**Status: READY FOR FIELD PILOT — NOT YET PASSED**

M23 requires permissioned real-service use and independent human review. Freeze the release/hash and thresholds before collection; use pseudonymous service IDs; record aggregate reference accuracy, stale output, privacy incidents, crashes/recovery, interventions and latency. Run `python -m ruach_core.pilot_eval <manifest>`.

Stop public use for privacy disclosure, stale/wrong public output, failed-open rights validation, corrupted persistence treated as healthy, ended-session mutation, or unrecovered crash with uncertain public state.

M23 may be marked DONE only after the agreed number of permissioned services passes the predeclared thresholds and every critical incident has a written disposition.
