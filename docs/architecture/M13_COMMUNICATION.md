# M13 Communication Engine

## M13.1 reviewed copy container

A WhatsApp recap or video description can be created only from an approved M12 intelligence draft backed by a sealed M9 sermon archive. The exact M12 payload SHA-256, immutable body and body SHA-256 are retained. A communication draft starts as `draft`; its own authenticated approval or rejection is separate from approval of M12. Revision means a new draft. There is no publish, send or congregation-facing endpoint.

## M13.2 optional model draft adapter

`CommunicationDraftAdapter` accepts an injected provider callable with a name and model version. The default server has no provider. A configured operator API requires `send_to_provider: true` for each generation request and owner/admin access to the source archive. The input includes the **approved M12 title, summary and points**, its cited verses from the verified archive, the channel, and the exact M12/archive hashes. It excludes raw audio, transcripts and account details. The source is capped at 100,000 JSON characters and the response at 20,000. The adapter accepts only an object with a `body` string; fields such as `status` or `publish` cause rejection. A body must still pass the channel's content bounds.

The provider call runs outside a database transaction. Before storage, RUACH checks that the M12 draft remains approved and its payload and archive hashes still match. Draft creation and model-run provenance then commit in one transaction. The immutable `communication_model_runs` record carries provider, model, canonical input and response SHA-256, source intelligence payload SHA-256, and requesting operator. A generated result has `source_kind: model_draft`, `status: draft`, and no path to self-approval. Provider exceptions are reported without exposing provider error text.

The callable can be local or externally hosted, but no vendor account or live external generation was configured or tested in this slice. The operator must review factual accuracy, translation rights and sharing permissions before approving outward copy. The presence of an approved M12 summary does not prove every sentence generated by a model is grounded. There is still no publish/send endpoint.

Example provider injection for a local integration:

```python
from ruach_core.communication import CommunicationDraftAdapter
from ruach_core.server import handler_factory

adapter = CommunicationDraftAdapter("configured-provider", "model-version", generate_callable)
handler = handler_factory(core, communication_provider=adapter)
```

Authenticated request: `POST /api/communication/generate` with `intelligence_draft_id`, `channel` (`whatsapp_recap` or `video_description`), and `send_to_provider: true`. On success it returns a draft with provenance for human review. A missing adapter returns HTTP 501.
